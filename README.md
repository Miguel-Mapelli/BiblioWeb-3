# BiblioWeb — Catálogo de Biblioteca

Protótipo front-end para a disciplina de Interação Humano-Computador.

## Executar

Abra `index.html` em um navegador moderno. Não há etapa de instalação ou compilação.

## Estrutura

- `index.html`: estrutura semântica, templates e telas.
- `style.css`: tokens de design, componentes, responsividade e temas.
- `script.js`: navegação, catálogo demonstrativo, filtros, empréstimos, reservas e painel do bibliotecário.

## Referência de experiência

A organização da consulta foi aproximada do catálogo Pergamum do IFSP: pesquisa geral, pesquisa avançada, autoridades, e-books, arquivo, acessibilidade, atos normativos e plano de ensino. A identidade visual BiblioWeb foi preservada, com navegação pública para consulta do catálogo.

## Funcionalidades demonstrativas

- Catálogo público sem exigir login para pesquisar.
- Pesquisa por título, autor e assunto, filtros por categoria e ordenação.
- Pesquisa avançada por título, autor, assunto e ano.
- Ficha bibliográfica e disponibilidade de cada obra.
- Login demonstrativo para estudante e bibliotecário.
- Empréstimos, reservas, devoluções e gerenciamento do acervo usando `localStorage`.
- Feedback visual, estados de disponibilidade, mensagens de confirmação e prevenção de ações acidentais.
- Layout responsivo, navegação por teclado e alternância de tema.

## Observação

Este projeto é um protótipo acadêmico com dados locais de demonstração. As áreas de autoridades, e-books, arquivo, atos normativos e plano de ensino apresentam pontos de navegação demonstrativos; integração com o catálogo institucional, autenticação real, circulação e dados oficiais dependem de API e autorização do IFSP. O site Pergamum foi usado como referência de organização e fluxo, não como fonte de código ou de dados.
